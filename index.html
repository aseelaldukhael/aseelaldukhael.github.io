Riyadh Coffee Map

A data pipeline and interactive Arabic dashboard that answers one question: which Riyadh districts have the most cafes, and which are less crowded? It merges OpenStreetMap and Overture Maps, cleans and de-duplicates the places, assigns each cafe to a district, and checks the result with automatic quality tests. Try it below: zoom, search for a cafe, or click a district.

  • Python
  • OpenStreetMap
  • Overture Maps
  • Medallion (Bronze / Silver / Gold)
  • Data Quality Tests
  • GitHub Pages
  • 3,270 cafes
  • 143 districts
  • 13 quality tests

TechCatalog Pipeline
